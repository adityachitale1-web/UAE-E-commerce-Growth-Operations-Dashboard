# SouqPlus Executive Dashboard

A comprehensive business intelligence dashboard for SouqPlus leadership to monitor business performance and operational health.

## Features

- **Unified Performance View**: Track orders, revenue, and key metrics across all dimensions
- **City Performance Analysis**: Identify top-performing and underperforming cities
- **Channel Insights**: Compare performance across Mobile App, Website, Social Media, and Marketplace
- **Category Analytics**: Monitor revenue and operational metrics by product category
- **Operational Health**: Track delivery rates, cancellation rates, and return rates
- **Fulfillment Center Monitoring**: Analyze performance across distribution centers
- **Interactive Filters**: Drill down by date range, city, channel, and category
